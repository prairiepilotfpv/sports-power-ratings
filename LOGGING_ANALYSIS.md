## Why calibrate-history Appears to Fail

The `calibrate-history` command cannot find completed games because:

```
Prediction dates: ['2026-01-26']
Recent game dates: 2026-04-12, 2026-04-10, 2026-04-09, 2026-04-08, 2026-04-07
Predicted games with scores: 0
```

**This is correct behavior:**
- Predictions are made for **upcoming/scheduled games** (April 2026)
- Calibration requires **completed games with scores** 
- Currently, there are no completed games in the predicted date range
- Once April games are played and scores added to the database, `calibrate-history` will successfully fit calibrators
